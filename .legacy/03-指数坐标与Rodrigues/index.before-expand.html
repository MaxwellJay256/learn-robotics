03.0引言WHY AXIS + ANGLE

上一课留下冗余。旋转矩阵用 9 个数描述只有 3 个自由度的旋转——看不出绕哪根轴、转了多少角，还附赠 6 个约束方程。「绕单位轴 \(\omega\) 转 \(\theta\)」才是旋转的自然语言，本课把这句话变成可计算的公式。

本课做两件事。正向：给定轴 \(\omega\) 与角 \(\theta\)，写出 \(R\)——指数坐标与 Rodrigues 公式（03.1）；反向：给定 \(R\)，取回 \(\omega\) 与 \(\theta\)——2024 Q1(b) 原题，20 分里的一半（03.2）。

为什么叫「指数」。因为 \(R\) 将以矩阵指数 \(e^{\hat{\omega}\theta}\) 出现——这不是比喻：它是幂级数的字面求和，而无穷级数会精确坍缩成三项。

  • 独立从 \(\dot{p} = \hat{\omega}p\) 出发推出 Rodrigues 三项式，并说出 \(\hat{\omega}^{3} = -\hat{\omega}\) 在其中起的作用
  • 给任意 \(R\) 五分钟内解出 \((\omega,\theta)\)，含 \(\theta = \pi\) 的除零边界（2024 Q1(b) 核心步骤）
  • 说出指数坐标的不唯一性：同一个 \(R\) 对应哪些 \((\omega,\theta)\)
03.1矩阵指数FROM ODE TO RODRIGUES

把旋转写成微分方程。点 \(p\) 绕单位轴 \(\omega\) 匀角速旋转：任意时刻速度垂直于 \(\omega\) 与 \(p\)，大小为 \(|p|\sin\angle(\omega,p)\)——恰好是叉积的定义。\(\dot{p}(t) = \omega\times p(t) = \hat{\omega}\,p(t)\)，初值 \(p(0) = p_0\)。叉积整体升格成一个矩阵作用。

矩阵也有指数。标量方程 \(\dot{x} = ax\) 的解是 \(x = e^{at}\)；把幂级数 \(e^{x} = \sum x^{n}/n!\) 中的 \(x\) 换成矩阵 \(\hat{\omega}t\) 依然良定义——矩阵自乘有定义，每一项都是 \(3\times3\) 矩阵。于是 \(p(t) = e^{\hat{\omega}t}p_0\)。矩阵指数不是新记号，是逐项求和。

无穷级数会坍缩。反对称矩阵满足 \(\hat{\omega}^{3} = -\hat{\omega}\)（凯莱–哈密顿定理的直接推论：特征值是 \(0,\pm i\)）。于是 \(n\ge3\) 的每一项都能化回 \(I\)、\(\hat{\omega}\)、\(\hat{\omega}^{2}\) 三个矩阵的倍数，三角级数求和后只剩三项：

\[ e^{\hat{\omega}\theta} \;=\; I + \hat{\omega}\sin\theta + \hat{\omega}^{2}\,(1-\cos\theta) \]

这就是 Rodrigues 公式。所有高阶项自动并入 \(\sin\theta\) 与 \((1-\cos\theta)\) 两个系数。

体检三连。\(\theta = 0\) 时三项式回到 \(I\)；\(\omega\) 取 \(z\) 轴时它退化成 02 课的平面旋转 \(\begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}\)（本演示就取 \(\omega = \hat{z}\)，让旋转画在纸面上）；\(e^{-\hat{\omega}\theta} = \left(e^{\hat{\omega}\theta}\right)^{\mathsf{T}}\)。任意 \(\omega\)、\(\theta\) 代入，\(\det\) 恒为 1。

操作。拖红色手柄扫 \(\theta\)，右侧看幂级数 \(S_1,S_2,S_3,\dots\) 逐项逼近精确解 \(R\)——收敛速度就是「级数为何可用」的直观证据。

ω = ẑ 的平面特例◎ 红色手柄 = 扫转角 θ
幂级数逐项求和 · 收敛过程θ = 0°

\(S_k = I + \hat{\omega}\theta + \frac{(\hat{\omega}\theta)^2}{2!} + \dots + \frac{(\hat{\omega}\theta)^k}{k!}\)，误差取 \(\max|S_k - R|\)。\(k=5\) 时误差已小到肉眼不可见——而 Rodrigues 给出的是精确和。

三项式闭合 · 数值验证det = 1

左：\(\hat{\omega}\)（由 \(\omega = \hat{z}\) 写出，注意 \(\hat{\omega}^{3} = -\hat{\omega}\)）；中：三个系数矩阵的现值；右：精确 \(R\)。三项相加就是级数的无穷项和——这就是坍缩的含义。

03.2逆推轴与角R → (ω, θ) · 2024 Q1(b)

逆向的需求。考题给一个具体的数值 \(R\)，要求取回 \(\omega\) 和 \(\theta\)。出发点是一条迹的恒等式：\(\operatorname{tr}R = 1 + 2\cos\theta\)——绕轴方向的特征向量在旋转中不动（特征值 1），另两个特征值是 \(e^{\pm i\theta}\)，迹是三者之和。

第一步取 \(\theta\)。

\[ \theta = \arccos\!\left(\frac{\operatorname{tr}R - 1}{2}\right) \]

\(\arccos\) 只返回 \([0,\pi]\)，天然给出「短方式」转角——答题写主值即可。

第二步取 \(\omega\)。\(R - R^{\mathsf{T}}\) 里只剩 \(\sin\theta\) 的信息：\(R - R^{\mathsf{T}} = 2\sin\theta\,\hat{\omega}\)。两边除以 \(2\sin\theta\) 得 \(\hat{\omega}\)，再从反对称的三个位置读出 \(\omega\) 的三个分量。使用条件：\(\sin\theta \neq 0\)。

\(\pi\) 陷阱（考试爱设的边界）。\(\theta = \pi\) 时 \(\sin\theta = 0\)，上一步除零失效。改走对称路线：\(R + I = 2\omega\omega^{\mathsf{T}}\)——对角元给 \(|\omega_i|\)，非对角元给符号（\(\omega_i\omega_j = (R+I)_{ij}/2\)）。面板里两条路线并排算给你看，什么时候切换一目了然。

不唯一性。\(\theta\) 加 \(2\pi k\) 后 \(e^{\hat{\omega}\theta}\) 不变——指数坐标到 \(R\) 是多对一；\(\arccos\) 的 \([0,\pi]\) 是人为选定的主值约定。同轴反向 \((-\omega,-\theta)\) 给出同一个 \(R\)，也是同一件事的另一面。

操作。按钮选转轴（含「随机斜轴」验证公式对任意 \(\omega\) 通用）；在画布上左右拖动即扫 \(\theta\)；点「θ=180°」看通用公式熄灭、对称路线接管。右下角实时核对恢复出的 \(\omega\) 与真值。
